
# Ticket BISI-1: Wi-Fi Connection Issue

## Environment
Company: SweetByte Bakery (Fictional)
Platform: Jira Service Management
Ticket Type: IT Support
Priority: Medium

## Problem
An employee reports that their laptop cannot connect to the office Wi-Fi.

Other employees can connect successfully, suggesting the issue may be specific to the employee's laptop.

## Initial Investigation
I created the ticket in Jira, assigned it to myself, and began investigating the issue.

I documented the reported symptoms and planned troubleshooting steps using an internal note.

## Troubleshooting Plan
1. Check whether Wi-Fi is enabled.
2. Confirm the correct network is selected.
3. Check for connection error messages.
4. Restart the wireless connection.
5. Check the IP address and network settings.
6. Test the connection again.

## Possible Solution
One possible fix is to forget the saved Wi-Fi network and reconnect using the correct credentials.

This solution would need to be tested before confirming the incident is resolved.

Investigation documented in Jira.
