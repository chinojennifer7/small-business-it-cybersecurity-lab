# Small Business IT & Cybersecurity Operations Lab

## Project Overview
This project simulates the IT and cybersecurity operations
of SweetByte Bakery, a fictional business with 25 employees
and two locations in Brooklyn, NY.

The purpose of this project is to gain hands-on experience
in IT troubleshooting, ticket management, cybersecurity
monitoring, and incident response.

## Tools Used
- Jira Service Management
- GitHub
- Python (planned)
- Google Colab (planned)
